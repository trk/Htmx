# ProcessWire HTMX Module (`Totoglu\Htmx`)

Server-driven HTMX v4 UI and stateful component framework for ProcessWire, featuring `HtmxCache` (`$htmxCache`) compile-time shape caching and zone-based composition.

## Language

### UI & Composition

**Ui**:
A stateless presentation element (`Totoglu\Htmx\Ui`) that renders HTML from structural parameters, content slots, and HTML/HTMX attributes without owning persistent server state.
_Avoid_: Widget, partial, view helper

**Atomic Ui**:
A leaf `Ui` element (such as `Title`, `Badge`, `Button`, `Image`, `Icon`, `Text`) that manages its own tag, visual classes, and value gate, compiling into its own standalone cache file.
_Avoid_: Sub-template, snippet, inline tag

**Container Ui**:
A composite `Ui` element (such as `Card`, `Overlay`, `Alert`, `Headline`, `Layout`, `Modal`) that defines named layout zones and orchestrates the placement of rendered `Atomic Ui` outputs or content strings.
_Avoid_: Wrapper, layout template

**Zone**:
A named structural region declared by a `Ui` class (for example `left`, `center`, `right` on a `Button`, or `top-left`, `top`, `top-right`, `center`, `bottom` on a `Card`) into which items and slots are placed.
_Avoid_: Position class, region hook, section

**Value Gate (`hasValue`)**:
The pre-cache check executed by every `Ui` element before computing a shape hash or touching the cache; if an element has no meaningful value to display, it immediately returns an empty string (`''`) without compiling or rendering empty HTML tags.
_Avoid_: Empty filter, post-render trim

### HtmxCache (`$htmxCache`)

**HtmxCache (`$htmxCache`)**:
The dedicated file and OPcache compilation engine (`Totoglu\Htmx\Cache\HtmxCache`, accessible via `$htmx->cache` or `wire('htmxCache')`) separate from ProcessWire's `$cache` (`WireCache`).
_Avoid_: WireCache, Blaze

**Shape**:
The immutable structural fingerprint of a `Ui` element consisting of its class name, source `filemtime`, structural parameters (`$shapeParams`), resolved `class` attribute, and active zone placement map.
_Avoid_: Cache key, props hash, template variant

**Slot Data**:
The dynamic, per-instance content values (`$slotParams` and rendered zone outputs) passed into a compiled `Shape` closure at runtime and evaluated by lightweight `if/else` checks.
_Avoid_: Static props, shape parameters

**Runtime Attributes**:
Instance-specific HTML and HTMX attributes (`hx-*`, `data-*`, `id`, `href`, `name`, `value`, `aria-*`) excluded from the `Shape` fingerprint and injected into named attribute slots (`root`, `link`, `title`, etc.) at execution time.
_Avoid_: Static attributes, structural classes

**Schema Cache**:
A compiled PHP file generated per stateful `Component` class that maps public property types (for hydration/dehydration) and invokable action/query method signatures without runtime reflection.
_Avoid_: State payload, reflection lookup

**State Payload (`hx__state`)**:
The HMAC-signed, time-expiring hidden input generated by `Component::renderStatePayload()` to preserve public component properties across HTMX requests.
_Avoid_: Session state, client store
